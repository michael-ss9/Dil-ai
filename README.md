Dil AI 🧠❤️

Tumhara personal all-in-one AI assistant — Teacher + Researcher + Writer + Programmer + Creative Partner, sab ek app mein!

✨ Features

- Knowledge & Learning — School/college subjects, step-by-step solutions, notes, quizzes
- Writing — Letters, emails, essays, stories, captions, slogans
- Coding — Python, JavaScript, HTML/CSS help, debugging, tech support
- Creative — Image prompts, story ideas, lyrics, design guidance
- Social Media — Content ideas, scripts, SEO, branding
- Research — Current info (web search), comparisons, facts
- Productivity — Study plans, schedules, project breakdowns

🏗️ How it works

Dil AI is a lightweight WebView wrapper around a single HTML file.
The app UI (15 KB) runs 100% on your phone, while the AI brain
(Google Gemini) runs in the cloud via API — that's why the whole
APK is only 10 KB! 🪶

Built with: Kotlin (Android) + HTML/CSS/JS + Gemini API
Built entirely from a phone using GitHub Actions — no PC needed! 📱

🚀 Build the APK yourself

1. Fork/clone this repo
2. GitHub Actions runs `.github/workflows/build.yml` automatically
3. Download `Dil-AI-APK` artifact → install → add your free Gemini API key

Get a free API key: https://aistudio.google.com/apikey
